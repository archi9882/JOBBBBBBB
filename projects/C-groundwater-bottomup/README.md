# 專案 C：地下水污染傳輸服務（bottom-up，你自己寫）

專案 A、B 是 Claude 速成、你拆解；專案 C 反過來：**由你從最底層一路寫上去**，Claude 只能拷問與審查，不寫程式。

```
L6 架構決策與否證案例
L5 自架平台（容器、k3d、監控）
L4 模擬與反問題 API
L3 監測井資料 ETL 與空間
L2 反求延散係數
L1 一維對流-延散求解器          ← 從這裡開始
```

## 強制機制
- `gate.toml` 定義每一層的條件：對應課程已出貨、對應的 grill 目標分數 ≥ 2、下一層測試已通過。
- `python tools/gate.py` 檢查每一層：條件未滿足卻放了 `.py`，結束碼為 1，CI 失敗。
- 所以你不能跳層，也不能在還沒拆懂 A、B 的對應元件前開始寫。

## 與第二冊的關係
L1、L2 的物理與數值內容在第二冊（地下水傳輸與求解器）第 12–14 章都有：ADE、Ogata–Banks、有限差分四格式、反問題可辨識性。那是參考，不是可以複製的程式；這一層的程式要你自己寫。

## 規則（無法用程式強制，靠你自己）
- Claude 在這個專案只做三件事：拷問（grill-me）、審查你寫好的程式、幫你查文件。不請 Claude 產生這個專案的程式碼。
- 用了任何外部程式片段，在該層的 `falsification.md` 或 `design.md` 寫明來源。
