以下分兩部分。數字都用 `dam_break(10, 1)` 的預設參數（L=1000、N=400、g=9.81）手算。

# 一、需要的基礎概念

## 流體力學（只需要這些）

1. **變數**：`h` 是水深，`u` 是流速，`g=9.81` 是重力加速度。`hu` 是單位寬度流量，也是動量的一種表示。
2. **淺水假設**：水平尺度遠大於水深，所以垂直方向的壓力等於靜水壓。壓力沿水深積分後得到 `g h²/2`，這就是動量通量裡壓力那一項。
3. **兩條守恆律**（無摩擦、平底）：
   - 質量：`h_t + (hu)_x = 0`
   - 動量：`(hu)_t + (hu² + g h²/2)_x = 0`
   - `hu²` 是水流自己搬運動量，`g h²/2` 是壓力推動。
4. **重力波速 `c = √(gh)`**：擾動在水上傳播的速度。`h=10` 時 c≈9.9 m/s，`h=1` 時 c≈3.13 m/s。往右傳的波速是 `u+c`，往左傳的是 `u−c`，這兩個叫特徵速度（characteristic speeds）。
5. **Froude 數 `Fr = |u|/c`**：小於 1 是亞臨界，波能逆流傳；大於 1 是超臨界，所有波都被沖往下游。程式 `SL >= 0` 那一支就是「所有波往右」的情況。
6. **兩種波**：
   - 稀疏波（rarefaction）：平滑展開。
   - 激波（shock，水中叫水躍）：水深和流速瞬間跳變。
   - 水壩潰決（dam break）的解是「向左一道稀疏波，向右一道激波」，中間夾一段平台。
7. **乾床**：`h≈0` 時 `u = hu/h` 會除以零，需要特別處理。

## 計算流體力學（只需要這些）

1. **有限體積法（FV）**：把空間切成格子，每格只存一個平均值。第 i 格的中心是 `(i+0.5)·dx`，這是程式第 51 行。
2. **數值通量（numerical flux）**：格子之間的介面上，通量要由左右兩格的值估計出來。守恆形式的更新式是「新值 = 舊值 − Δt/Δx × (右介面通量 − 左介面通量)」。
3. **Riemann 問題與 Riemann 求解器**：介面左右各是一個常數狀態，問這個階梯會長出什麼波、通量是多少。精確解很貴，所以用近似解。HLL 是其中最簡單的一種。
4. **HLL 的想法**：假設只有兩道波，左波速 `SL`、右波速 `SR`，中間是一個均勻狀態。算出的通量是：
   `F = (SR·FL − SL·FR + SL·SR·(UR−UL)) / (SR−SL)`
5. **顯式前進 Euler 時間步進**：用「現在」的值直接算「下一刻」。簡單，但有穩定性限制。
6. **CFL 條件**：一步之內，波最多跨過一格，即 `Δt ≤ CFL·Δx / max(|u|+c)`。超過就會數值爆炸。`cfl=0.9` 表示用到上限的 90%。
7. **數值擴散**：一階方法會把激波抹平成幾格寬的斜坡。這是方法的代價，不是 bug。
8. **邊界條件**：邊界格沒有外側鄰居，所以補一個虛擬格（ghost cell）。這裡補成和邊界格相同，叫透射或零梯度。
9. **一致性**：左右狀態相同時，通量必須退化成該狀態的真通量。HLL 滿足這點：若 `UL=UR` 則 `Fhll = FL`。
10. **收斂**：格子越細，結果應越接近解析解。這是下一個拷問目標 `A/analytic-and-convergence`，這裡不展開。

# 二、程式逐項說明

## 常數與資料結構
- `G = 9.81`：重力加速度。
- `H_DRY = 1e-8`：小於這個水深就當乾。
- `Result`：回傳包。`x` 是格心座標，`h`、`u` 是最終水深與流速，`t` 是實際走到的時間，`steps` 是步數，`mass0` 和 `mass` 是初始與結束的總水量。

## `_velocity(h, hu)`
- 輸入：水深陣列與 `hu` 陣列。輸出：流速 `u = hu/h`，乾格給 0。
- `np.maximum(h, H_DRY)` 防止除以零。`np.where` 兩邊都會先計算，所以分母必須先保護。

## `_flux(h, hu)`
- 輸出形狀是 `(2, n)`：
  - 第 0 列是質量通量 `hu`。
  - 第 1 列是動量通量 `hu·u + g h²/2`。
- 它只依賴 `_velocity`。

## `hll_flux(hL, huL, hR, huR)`
- 輸入：每個介面的左側格與右側格的狀態，四個陣列，每個介面一個元素。輸出：每個介面的通量，形狀 `(2, 介面數)`。
- 步驟：
  1. 求左右的 `u` 與 `c`。
  2. `SL = min(uL−cL, uR−cR)`：取左右最左的波速。`SR = max(uL+cL, uR+cR)`：取最右的波速。這樣保證兩道波把所有訊號都包在裡面。
  3. 算 `FL`、`FR` 與狀態 `UL`、`UR`。
  4. `denom` 防止 `SR−SL` 為零。
  5. 三選一：
     - `SL >= 0`：所有波往右，介面只受左邊影響，用 `FL`。
     - `SR <= 0`：用 `FR`。
     - 否則用 HLL 混合公式 `Fhll`。

## `dam_break(...)` 的引數
- `h_left`、`h_right`：壩左右的初始水深。
- `L=1000`：水道總長（公尺）。`x0=500`：壩的位置。
- `N=400`：格數，所以 `dx = 2.5`。
- `t_end=20`：模擬多少秒。
- `cfl=0.9`：時間步安全係數，必須在 (0, 1]。

## `dam_break` 的主迴圈，逐步
1. 檢查 `cfl`，建 `dx`、格心 `x`。
2. 初始：壩左邊水深 `h_left`，右邊 `h_right`，`hu` 全為 0（靜止）。記下 `mass0`。
3. 每一步：
   - 算 `u`，得到全場最大波速 `smax = max(|u|+√(gh))`。
   - `dt = min(cfl·dx/smax, t_end−t)`。後半讓最後一步剛好停在 `t_end`。
   - 補虛擬格：`hg`、`hug` 長度變成 N+2。
   - `hg[:-1]` 與 `hg[1:]` 配對，得到 N+1 個介面的左右狀態，送進 `hll_flux`。
   - `F[:,1:] − F[:,:-1]` 就是每格「右介面減左介面」，套進更新式，更新 `h` 和 `hu`。
   - 乾床修正：`h < H_DRY` 的格子，水深截為非負、`hu` 設 0。
   - `t += dt`、`steps += 1`。
4. 結束：回傳 `Result`，流速由 `hu` 換算回 `u`。

## 呼叫脈絡

```
dam_break
 ├─ 每步開頭：_velocity ──> smax ──> dt
 ├─ 補虛擬格 ──> hll_flux
 │               ├─ _velocity（算 uL, uR）
 │               └─ _flux（算 FL, FR）
 ├─ 通量差 ──> 更新 h, hu
 └─ 乾床修正 ──> 下一步
```

## 用數字走一遍第一步（壩所在的介面）
- 左格 `h=10`、右格 `h=1`，都靜止。
- `cL=√98.1≈9.905`、`cR≈3.132`。
- `SL = min(−9.905, −3.132) = −9.905`，`SR = max(9.905, 3.132) = 9.905`。
- 因為 `SL<0<SR`，走 HLL 公式：質量通量 `= (9.905·9.905·9)/(19.81) ≈ 44.57`，為正，代表水往右流。
- `smax≈9.905`，所以 `dt = 0.9·2.5/9.905 ≈ 0.227`，`dt/dx ≈ 0.0909`。
- 壩左格：`h = 10 − 0.0909·(44.57 − 0) ≈ 5.95`。壩右格：`h = 1 + 0.0909·(44.57 − 0) ≈ 5.05`。
- 兩格合計 `5.95 + 5.05 = 11`，與原來的 `10 + 1` 相同，質量守恆。
- 第一步變化很大，是因為初始階梯最陡，之後會快速平滑下來。

## 質量守恆的精確條件
更新式使內部介面的通量一加一減互相抵銷，所以：

`mass − mass0 = −（右邊界流出的質量 − 左邊界流入的質量）` + 乾床截斷的修正量

兩項各自的情況：
- 邊界項：透射邊界的虛擬格等於邊界格，邊界介面通量就是邊界格的通量。只要波還沒到達邊界，邊界格仍是初始靜止狀態，質量通量為 0，這項為 0。波到達之後水會流出（或流入），總水量就會改變，這不是 bug，是邊界條件的效果。
- 截斷項：`h < H_DRY` 時 `max(h, 0)` 只改負值，把負水深補成 0，等於憑空加上很小的水量。只有出現負水深時才有，量級遠小於邊界項。

實跑結果（`L=1000`、`x0=500`、`N=400`，在 WSL `jobprep` 環境）：

| h_left | h_right | t_end | mass0 | mass | mass − mass0 |
|---|---|---|---|---|---|
| 10 | 1 | 20 | 5500 | 5500 | 0.0 |
| 10 | 1 | 100 | 5500 | 4855.68 | −644.3 |
| 10 | 0 | 20 | 5000 | 5000（4999.999999999999） | −9.1e-13 |
| 10 | 0 | 100 | 5000 | 4551.69 | −448.3 |

解讀：
- `t_end=20`：左側稀疏波前緣速度約 `−√(g·10) ≈ −9.9 m/s`，20 秒只走約 198 m，離左邊界（距壩 500 m）還很遠；右側激波更慢。波沒碰到邊界，差值只剩浮點誤差（0 或 1e-13 量級）。
- `t_end=100`：波已經碰到邊界，水從兩端流出，質量減少數百。
- 所以「mass0 與 mass 相等」要改寫成：波尚未抵達邊界時，在浮點誤差內相等；波抵達後，差值等於邊界淨流出量。
- 本表沒有單獨量出截斷項的大小，t=20 的結果只能說明它不大於浮點誤差的量級，不能證明它恆為 0。

拷問時可能被問到「質量在什麼情況下會變」，答案是這兩項。
