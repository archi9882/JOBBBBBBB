# 05/02　時區與重新取樣

- Phase：05-etl（ETL 與資料品質）
- 能力：E1 ETL
- 狀態：由 `python tools/ship_check.py` 判定，不手寫

## 問題
UTC 與台灣時間混用、時雨量標籤錯一格，是最常見的悄悄出錯。

## 數學／原理（完整推導寫在 math.md）
時雨量通常指「該小時結束時」的累積：區間 (t−1h, t]，標籤 t。

## 測試：通過條件
兩種來源合併後，同一場雨的時序對齊；resample 的區間與標籤有測試。

## AI 否證目標
pandas resample 預設區間左閉、標籤在左，與「結束時累積」差一小時。
