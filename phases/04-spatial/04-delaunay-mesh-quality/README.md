# 04/04　Delaunay 網格品質

- Phase：04-spatial（空間資訊）
- 能力：S1 空間資訊
- 狀態：由 `python tools/ship_check.py` 判定，不手寫

## 問題
產生三角網格，用品質指標找出限制時間步長的元素。

## 數學／原理（完整推導寫在 math.md）
最小內角、內切圓半徑；Δt ∝ 最小特徵長度。

## 測試：通過條件
品質報表：最小角分布、最差 10 個元素的位置。

## AI 否證目標
在經緯度上做 Delaunay；忽略狹長三角形對 CFL 的影響。

## 出貨條件（四項都完成才算這堂課完成）

2. `code/`：可在 WSL2 Ubuntu 直接執行的程式，附實跑輸出。
3. `tests/`：把「通過條件」寫成 pytest，且全部通過。
4. `falsification.md`：至少一筆 AI 否證紀錄（AI 說了什麼、怎麼驗證、結論）。
