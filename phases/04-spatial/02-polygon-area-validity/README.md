# 04/02　多邊形面積與有效性

- Phase：04-spatial（空間資訊）
- 能力：S1 空間資訊
- 狀態：由 `python tools/ship_check.py` 判定，不手寫

## 問題
手寫鞋帶公式，用它否證函式庫輸出，並檢查拓撲有效性。

## 數學／原理（完整推導寫在 math.md）
A = ½ Σ (x_i y_{i+1} − x_{i+1} y_i)；正負號＝頂點方向。

## 測試：通過條件
手寫面積與 shapely 一致到 1e-9；自相交多邊形被抓出。

## AI 否證目標
AI 對自相交多邊形回報面積，不檢查 is_valid。
