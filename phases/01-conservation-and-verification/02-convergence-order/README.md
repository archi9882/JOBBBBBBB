# 01/02　網格收斂與觀測收斂階

- Phase：01-conservation-and-verification（守恆與驗證）
- 能力：M1 數值模擬與物理判斷
- 狀態：由 `python tools/ship_check.py` 判定，不手寫

## 問題
只跑一個網格不能說「收斂」；用三層網格量出收斂階。

## 數學／原理（完整推導寫在 math.md）
e(Δx) ≈ C Δx^p ⇒ p = ln(e_N / e_2N) / ln 2。

## 測試：通過條件
上風格式在平滑解上 p ≈ 1（0.9–1.1）。

## AI 否證目標
AI 宣稱二階，但用的是一階格式；或只比較兩個很粗的網格。
