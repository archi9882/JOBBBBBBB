# 網格收斂與觀測收斂階：推導

**步驟 1　誤差模型。** 一個 p 階格式在網格夠細時，誤差主要由截斷誤差的首項決定：e(Δx) ≈ C Δx^p，C 與 Δx 無關。這是假設，只在「漸近範圍」（asymptotic range）成立，網格太粗時不成立。

**步驟 2　兩個網格相除，消去未知的 C。** 上一步留下兩個未知數 C 與 p。用 Δx 與 Δx/2 各算一次：

  e_N ≈ C Δx^p，e_{2N} ≈ C (Δx/2)^p

相除：e_N / e_{2N} = 2^p。

**步驟 3　取對數解出 p。**

  p = ln(e_N / e_{2N}) / ln 2

程式中 `observed_orders` 用一般式 p = ln(e_i / e_{i+1}) / ln(N_{i+1} / N_i)，網格比不是 2 時也適用。

**步驟 4　上風格式為何是一階（Taylor 展開）。** 上風更新 c_i^{n+1} = c_i^n − Cr (c_i^n − c_{i−1}^n)，Cr = uΔt/Δx。把精確解代入並在 (x_i, t^n) 展開：

  c(t+Δt) = c + Δt c_t + (Δt²/2) c_tt + …
  c(x−Δx) = c − Δx c_x + (Δx²/2) c_xx − …

代回後，c_t + u c_x 的項按 PDE 等於 0；剩下的首項為 (Δt/2) c_tt − (uΔx/2) c_xx。用 c_tt = u² c_xx（對 PDE 再微分一次）得 −(uΔx/2)(1 − Cr) c_xx，與 Δx 成正比：一階。這一項的形式像擴散，係數就是第二冊推過的數值擴散 D_num = (uΔx/2)(1 − Cr)。

**步驟 5　Lax–Wendroff 為何是二階。** Lax–Wendroff 多加了 ½ Cr² (c_{i+1} − 2c_i + c_{i−1})，正好抵銷步驟 4 的 Δx 一次項，首項變成 Δx² 階（色散項 c_xxx）。

**步驟 6　不連續解為何降階。** 步驟 1 的誤差模型需要解夠平滑，Taylor 展開才成立。方波在跳躍處沒有導數，誤差集中在跳躍附近一個被數值擴散抹開的區域。對線性對流，r 階線性格式在 L1 下的收斂階約為 r/(r+1)：上風約 1/2、Lax–Wendroff 約 2/3（引用，未推導；常見教科書結果，出處未查證）。實測：上風 0.499、Lax–Wendroff 在 N=400 為 0.591，仍在往 2/3 靠近。

**補充　非線性激波不同。** 淺水方程的激波是壓縮性的（特徵線匯聚），會自我銳化，一階格式在 L1 下通常約一階；線性不連續（例如接觸間斷）沒有這個機制，所以降到約 1/2。Claude 另以 Burgers 方程的激波（u_L=1、u_R=0）用一階守恆上風格式實測，N=200→1600 的 p 為 1.000（該程式未收入本課）。這是後面 02/04 用潰壩解比較時要分開看的原因。
