# 01/03　製造解（MMS）

- Phase：01-conservation-and-verification（守恆與驗證）
- 能力：M1 數值模擬與物理判斷
- 狀態：由 `python tools/ship_check.py` 判定，不手寫

## 問題
沒有解析解時，自己造一個解，反推源項，再檢查程式能否還原。

## 數學／原理（完整推導寫在 math.md）
選 h*(x,t)，代入 PDE 得 S = ∂h*/∂t + ∂(h*u)/∂x，把 S 加進求解器。

## 測試：通過條件
MMS 誤差隨網格加密以理論階數下降。

## AI 否證目標
源項推導漏項（乘積法則只展開一半），誤差停在固定值不下降。
