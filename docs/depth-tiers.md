# 學習深度標注（只標注，不更動任何課程內容）

來源觀點：系統層級的理解歸人，語言與技術細節歸 Agent；某個細節確實重要時，才深入。
本檔是外掛式標注：不修改 `phases/` 任何檔案，也不影響 `CATALOG.md`、`tools/`、`learning-paths/`。

## 判斷四問（任一為「是」就往 A 靠）

- Q1 錯了會悄悄錯嗎？（結果看似合理但有偏差）
- Q2 錯了很貴嗎？（資料毀損、安全、容量、授權）
- Q3 我沒有獨立方法驗收嗎？（沒有解析解、守恆量、測試可比對）
- Q4 職缺明寫、面試會被追問嗎？

## 三級

- **A 親手做**：Q1 或 Q2 為是，且驗不了；或是職缺的判斷核心。
- **B Agent 做、你驗收**：錯誤會顯現，或有基準可比對。你負責設計驗收與讀懂結果。
- **C 只讀懂**：錯了便宜、可回頭修。

校準規則：同類東西 Agent 連續錯兩次 → 升一級；連續三次都對 → 降一級。
時間預算：A 約佔 30–40%。
新領域（你分數為 0 的）第一次先做最小版，之後再放手。
