# 數值分析儲備課程

海嘯實驗室（`lab/`）是主線。這裡收的是**數值分析與計算幾何**的課程：實驗室目前用不到，但之後要做符合職缺的專案（自己寫求解器、專案 C 的對流-延散、二維網格）時會用到。卡片需要時才回頭做，不排進每天的進度。

| 課 | 主題 | 什麼時候會用到 |
|---|---|---|
| 01/01 | 控制體積與連續方程（已出貨） | 專案 C 第一層 |
| 01/02 | 網格收斂與觀測收斂階（已出貨） | 卡 14 的理論背景 |
| 01/03 | 製造解（MMS） | 沒有解析解時驗證自己的求解器；專案 C 第一層 |
| 01/04 | 靜水測試 | 加入地形後的求解器 |
| 02/01–02/06 | 淺水方程有限體積法：Saint-Venant 與 CFL、Lax–Friedrichs、HLL、潰壩解析解、乾濕邊界、敏感度分析 | 拆解專案 A；想自己寫一個比 COMCOT 簡單的海嘯求解器時 |
| 04/02 | 多邊形面積與有效性（已出貨） | 淹水範圍面積；大座標捨入誤差 |
| 04/03 | 徐昇式多邊形（Voronoi） | 職缺列出的計算幾何 |
| 04/04 | Delaunay 網格品質 | 職缺列出的計算幾何與網格生成；非結構網格求解器 |

### 海嘯數值方法（10/01–10/07，2026-11-16 新增）

COMCOT 用到、但上面各課沒有教的數值方法。每堂的推導、可在瀏覽器執行的程式與實測輸出在 [流體力學與 CFD 從零開始](https://claude.ai/artifact/UNkoMqkLDbPB72QRsM4TQf) 第 16 章。

| 課 | 主題 | 什麼時候做 |

| 10/03 | 蛙跳格式與交錯網格 | 卡 04 之後 |
