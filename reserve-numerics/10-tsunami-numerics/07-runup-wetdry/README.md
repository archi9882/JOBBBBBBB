## 問題
水淹上陸地時，數值方法要守住哪些性質？

## 數學／原理
非線性淺水方程、HLL、靜水重構（Audusse 等 2004）；Synolakis (1987) 溯上律 R/d = 2.831√cotβ (H/d)^{5/4}。

## 測試：通過條件
靜水測試最大流量 < 1e-12；1:19.85 斜坡、H/d = 0.0185 的溯上隨網格加密向溯上律收斂（N = 3000 時差 < 5%）。
