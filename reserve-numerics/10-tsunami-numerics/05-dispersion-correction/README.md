## 問題
怎麼用淺水方程的成本得到色散波的效果？

## 數學／原理
蛙跳數值色散 (kΔx)²(1−Cr²)/24 等於物理色散 (kh)²/6 → Δx = √(4h² + ghΔt²)（Yoon 2002 的隱藏網格）。

## 測試：通過條件
kh ≤ 0.2 時兩種相速度差 < 1e-4；寬 12 km 隆起走 1500 km，最佳格距與精確色散解的最大差小於細網格非色散解的一半。
